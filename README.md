# Company Profile CV. Adhyasta Sylva Jaya

Website statis (HTML/CSS/JS), tanpa build.

- `index.html` : website utama (responsif)
- `profile-slides.html` : versi slide 1280x720
- `favicon.svg`, `logo.svg` : identitas visual

## Jalankan lokal
```
python3 -m http.server 8000
```
Buka http://localhost:8000

## Deploy
GitHub Pages: Settings > Pages > Deploy from a branch > main, / (root).
Domain sendiri: tambahkan file `CNAME` berisi nama domain, lalu arahkan DNS.
